      Notebook evidence ledger (SHA-256)

        Properties stated about the logic

        -- H01: a tracked person in the drop-zone for N frames always alerts
theorem h01_fires (p : Track) (t : Frame) :
  loadMoving t → (∀ k < N, inDropZone p (t - k)) → alert .H01 p t

-- Debouncing never suppresses a P1 alert
theorem debounce_keeps_p1 (r : Rule) :
  r.priority = .P1 → alert r d t → emitted (debounce r d) t

-- Every alert has a ledger entry
theorem alert_has_evidence :
  alert r d t → ∃ e ∈ ledger, e.rule = r.id ∧ e.time = t

        Illustrative Lean 4 statements based on the examples in the field notes. The notebook's CGA.lean now states and proves debounce_keeps_p1 and alert_has_evidence over its own rule-engine model; they haven't been machine-checked yet (set CFG.run_lean = True in Colab).

        What the proofs don't cover. They show the rule logic is right given the detections. They don't show the detections are right, so each rule also shows its measured detection quality: MCC for this rule on validation clips.
